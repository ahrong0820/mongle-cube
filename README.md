# 몽글큐브

가족이 휴대폰과 태블릿 최대 5대에서 이유식 큐브의 개수와 냉동 14일 기한을 함께 관리하는 작은 모바일 웹앱입니다.

현재 상태: **Supabase 공유 연결 · GitHub Pages 자동 배포 운영 중**

## 들어간 기능

- 큐브 이름, 베이스·토핑·간식·기타 역할, 제작 날짜·시간, 만든 개수 등록
- 1개 용량(g/mL)과 메모는 선택 입력
- 제작 시각부터 정확히 14일 뒤 기한 자동 계산
- 3일 이내와 기한 지남을 색과 문구로 함께 표시
- 기한이 가까운 제작분부터 정렬
- 카드에서 `먹었어요 -1`, `추가 +1`
- 오늘부터 7일간 아침·점심·저녁·간식 식단 계획, 한 끼에 여러 큐브 동시 선택
- 식단의 `먹었어요`를 누르면 해당 큐브 1개 차감과 누적 기록을 한 번에 처리
- 먹은 시간과 큐브 이름을 날짜별 누적 기록지로 보관
- 지난 먹은 기록의 날짜·시간, `잘 먹음·보통·거부·관찰 필요` 반응과 100자 메모 수정
- 최근 7일 섭취량과 큐브별 반응 요약
- 월간 달력에서 날짜별로 먹은 큐브와 반응을 한눈에 확인
- 생일·이유식 시작일을 한 번 설정하면 날짜별 `D+`와 이유식 일차 자동 계산
- 선택한 날의 베이스·토핑·간식, 자동 `NEW`, 큐브 기준 먹은 양과 관찰 반응 요약
- 어느 날짜의 먹은 기록이든 개별 삭제하고 가능한 경우 해당 큐브 재고 1개 복원
- 전체·남아 있음·임박/지남·다 먹음 재고 필터
- 수정, 삭제, 0개 아래로 내려가지 않는 수량 보호
- Supabase 연결 전에는 브라우저 로컬 저장
- 연결 후에는 초대된 최대 5개 기기 사이 실시간 갱신
- 360px 모바일부터 데스크톱까지 반응형 화면
- 직접 제작한 아기 곰·이유식 그릇 일러스트와 파비콘

## 로컬에서 실행

Node.js 22 이상과 pnpm을 사용합니다.

```bash
pnpm install
pnpm dev
```

터미널에 표시되는 `http://localhost:5173` 주소를 열면 됩니다. 환경값을 넣지 않은 상태에서는 브라우저에만 저장되는 로컬 시험 모드로 동작합니다.

```bash
pnpm typecheck  # TypeScript 검사
pnpm test       # 자동 테스트
pnpm build      # GitHub Pages용 빌드
pnpm preview    # 빌드 결과 미리보기
```

## 여러 휴대폰과 공유할 때

로컬 화면을 확인한 다음 [Supabase 연결 안내](docs/supabase-setup.md)를 순서대로 진행합니다. 별도 로그인 화면은 없으며, 같은 초대 주소를 사용할 휴대폰·태블릿에서 한 번씩 여는 것으로 연결됩니다.

GitHub Pages 자동 배포는 [.github/workflows/deploy.yml](.github/workflows/deploy.yml)이 담당합니다.
